1. JDK (Java Development Kit) - набор инструментов разработчика. Включает виртуальную машину, компилятор, обработчик и т.д
JRE (Java Runtime Environment)  - это виртуальная машина с дополнительными библиотеками. Используется только для запуска java-программ.
JVM (Java Virtual Machine) — виртуальная машина, выполняющая байт-код.
JDK включает в себя JRE, а JRE - JVM.
Разработчику необходимо установить JDK. Конечному пользователю - JRE.

2. Байт-код - это промежуточный формат кода, который может запустить JVM на своей платформе.
Write Once, Run Anywhere — написал один раз, запускай везде. Возможность запуска одного кода на разных платформах 
благодаря JVM.
